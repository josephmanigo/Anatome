ANATOME 1.4.8 - CASE VISUALS AND AUTOMATIC REFRESH
Android version code 16 | org.thoraxlab.learning

INSTALL
Use Anatome-1.4.8.apk. Update the existing app through Meta Quest Developer Hub;
keep its app data. No headset installation was performed during this delivery.

CHANGES
- Continuous airway training head with integrated facial contours, folded ears,
  warmer silicone material, closed eyelids, lip detail and a fitted base.
- Rounded, gently convex skin inserts with existing tissue appearance assets.
- Rounded vascular channel bends; original interaction routes remain fixed.
- Quest defaults to Auto - highest supported headset refresh rate.
  Old saved 72 Hz defaults migrate to Auto once. Other preferences are preserved.
  Supported manual refresh choices remain available.
- Existing side instruments, interaction anchors, clinical objectives and the
  OpenGLES3 Quest driver workaround are preserved.

QUICK HEADSET CHECK
1. Open Anatomy Cases, then Asthma or Pneumonia. Inspect the head from the front
   and side, and complete the mouthpiece interaction.
2. Open Pneumothorax or Pleural Effusion. Inspect the skin layers and access gap.
3. Open a vascular case and check the guidewire route through the rounded channel.
4. In Graphics & display, confirm Headset refresh rate is Auto. Check the FPS
   display and comfort over sustained use. Auto requests the maximum supported
   display mode; it does not guarantee that every scene renders at that FPS.

EVIDENCE
verification-summary.json identifies the exact APK hash and verification results.
Previews are desktop renders of the actual Unity models. Player captures and
simulator checks are local evidence, not physical-headset acceptance.

LIMITS
Physical headset appearance, comfort, native refresh acceptance and sustained FPS
remain to be checked. The existing Android Debug signing identity is retained for
sideload updates; this is not a publisher-signed store release.
