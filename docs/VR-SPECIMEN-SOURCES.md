# VR specimen appearance and layer provenance

The VR revision uses the existing 249-entry thorax catalog: 243 tissue structures and six reference annotations. It does not replace the healthy specimen with a generated body or alter source geometry to make the appearance more dramatic. The original FBX meshes, LOD meshes, collision geometry, source textures and source records are retained.

| Layer | Stable IDs and source | What is represented |
|---|---|---|
| Skin | `FMA7163`, BodyParts3D 4.0 source skin envelope | The original regional surface is retained. The prior production mesh includes a region trim, regional closure surfaces and an authored inward wall, nominally 1.8 mm with local clamping. It is an enclosing teaching shell, not measured dermal histology. |
| Subcutaneous tissue | `REC_fat`, authored reconstruction derived from the BodyParts3D skin envelope | A separate removable layer underneath the skin. Thickness and clearance are author-selected teaching approximations, not a segmentation of a particular person's adipose tissue. |
| Thoracic fascia | `REC_fascia`, authored reconstruction derived from the same envelope | A separate teaching layer. It does not resolve every superficial/deep fascial subdivision. |
| Pectoralis major | `FMA34690`/`FMA34691` clavicular parts, `FMA79979`/`FMA79980` sternocostal parts, `FMA45874`/`FMA45875` abdominal parts | Source BodyParts3D muscle geometry, with right and left identities retained. |
| Pectoralis minor | `FMA13375`/`FMA13376` | Source right/left geometry, deeper than pectoralis major. |
| Serratus anterior | `FMA13398`/`FMA13399` | Source right/left geometry. |
| Intercostals | `FMA9756`, `FMA9757`, `FMA9758` | Source external, internal and innermost intercostal geometry. Each catalog item may include several connected regions. |
| Deeper specimen | Existing skeletal, lung, airway, cardiac, vessel, nerve and membrane catalog entries | The actual installed meshes remain behind the superficial layers, so moving or cutting a covering surface reveals the existing interior geometry. Empty-space/reference annotations remain non-tissue and uncuttable. |

The downloaded archive, source metadata and checksums are recorded in `source/source-manifest.json`; structure-specific source kind and production notes are retained in `exports/anatomy-catalog.json`. The five lung lobes retain their existing Medical Augmented Learning source records. No new third-party anatomy assets are introduced by this appearance revision.

`VRSpecimenAssets.Prepare()` creates a separate `Resources/Learning/Specimen` collection containing 512-pixel albedo and normal maps and URP materials. Subtle albedo variation, lobular modulation, fine striation and lung surface variation are original procedural illustration. Their purpose is to make close-range tissue surfaces legible; these patterns are not histological images, segmented vessels, measured fibre orientation, or additional anatomical landmarks. Original source UVs remain in use; normal maps use existing imported tangents and rebuilt cut-mesh tangents. Actual XR review showed that visible skin bump detail exaggerated the packed UV islands, so revision 2 disables exterior skin normal mapping and uses low-contrast skin albedo with reduced sheen. Mipmaps, trilinear filtering and Android ASTC 6×6 compression are declared explicitly. No displacement is applied to a mesh or collider.

The cut surface uses a separate tissue-specific interior material. The existing bone-cut shader and depth-derived cortical/cancellous appearance remain intact. That bone contrast is an existing teaching approximation rather than a segmentation of actual cortex. Native cutting still determines the output geometry: appearance does not manufacture a lumen or internal organ that the source model does not contain.

`VRSpecimenPresentation` keeps the actual deeper specimen visible during guided dissection. It does not award completion, delete overlying tissue automatically, or move fragments on the learner's behalf. Its layer controls are exploration cutaways and must remain outside assessment assistance unless the rubric explicitly permits them. `TryGetExposedSurface` first checks seven bounds directions, then up to 256 cached actual triangle-centroid directions for thin or curved structures. Each candidate still requires a real target collider hit without nearer anatomical obstruction, and saturated queries fail closed. Identification and case teaching windows explicitly name the removed coverings and award no exposure credit. Guided exposure combines surface access, ordered objectives, a committed opening and physical lifting before granting credit.

One separate validated working mesh is created for `FMA9757`. Its imported source contains an inverted, disconnected six-triangle component of approximately −2.81 × 10⁻¹⁵ m³. `LearningCutMeshRepair` requires the exact diagnosed topology and bounded numerical-artifact measurements before removing those six indices from a clone (3,976 → 3,970 triangles). It retains every source vertex, normal, tangent and UV and verifies unchanged referenced bounds; three native cut probes must pass before the derived asset is saved. The source FBX is unchanged, and the imported original remains separately retained by `AnatomyStructure`. `qa/vr-fma9757-derived-mesh-audit.json` records the source hash, removed indices, bounds and cut results. This is a targeted working-mesh repair, not a newly measured anatomical reconstruction.

The examination drape and neutral fill/boundary lights are laboratory presentation elements. The drape has no anatomy identity, collider or assessment role. These changes require running-player and headset visual review; no “10/10” quality or headset frame-rate measurement is implied by successful asset generation.
