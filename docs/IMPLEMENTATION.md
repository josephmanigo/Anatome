# Thorax Lab implementation contract

Approved target: a fresh adult-male gross-thorax asset set and photo-inspired 12 x 9 x 3 m teaching lab, Unity 6000.3.19f1 / URP / OpenXR / XRI, Windows demonstration and Quest 3 Android ARM64 build.

The three required modes are Explore and Reassemble, Guided Dissection, and Free Dissection. Free cutting includes soft tissue and a bone saw for ribs/sternum. Runtime cutting must preserve lumens, provenance, valid previous state on failure, ten-step undo, reset, a 100,000-triangle active-result limit, and a 32-fragment session limit.

Source policy: current official BodyParts3D 4.0 CC BY 4.0; public-domain reference images and original documented reconstructions. No Z-Anatomy or previous ANATOME derived geometry. Raw source is immutable. Source-backed does not mean independently anatomically validated. Professional evaluation is not a delivery requirement.

Required anatomy: thoracic skin, subcutaneous/fascial layers, pectorals, serratus, intercostals, ribs 1-12, cartilage, sternum, T1-T12/discs, shoulder girdle context, lungs/lobes, airways, pleura, diaphragm, heart/chambers/septa/valves, pericardium, coronary/great/pulmonary vessels, esophagus, azygos, vagus/phrenic/sympathetic/intercostal nerves and thoracic duct.

Acceptance evidence must distinguish: implemented; locally validated; Android built; actual-headset tested. Quest 3 is available later. Performance target 72 FPS, initial 600k visible triangle / 200 draw-call budgets; budgets and desktop results do not establish headset performance.

No accounts, progression, formal assessments, multiplayer, bleeding/physiology, or medical device claims. One adult male teaching specimen; English labels and source IDs; controller input; clean laboratory presentation.
